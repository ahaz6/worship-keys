WORSHIP KEYS SETS

This folder is the offline handoff between the Worship Keys Cloud Planner and
the local live host on the church Mac.

1. Install Google Drive for desktop on the home and church Mac.
2. In the Worship Keys Cloud Planner, choose "Connect Drive folder" once in
   Chrome and select this locally synchronised folder.
3. Worship Keys writes "Worship Keys Current.worship-keys.json" here.
4. On Sunday, open the local Worship Keys host on the church Mac and choose
   "Load from Drive".
5. Start audio and use "Show join code". That QR joins the current local LAN
   session and does not depend on the public Vercel address.

Supabase is the private working copy. This Drive folder is the portable,
offline-ready mirror. Avoid editing the JSON file by hand.
